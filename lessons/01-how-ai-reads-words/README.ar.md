# الدرس ٠١ — كيف يقرأ الذكاء الاصطناعي كلماتنا؟

[English](README.md) · [افتح التجربة](index.html)

تستخدم التجربة **أداة تعليمية مبسطة لتقسيم النص** وإعطاء الأجزاء أرقامًا تعليمية. هذه الأرقام ليست معرّفات الرموز في نموذج لغوي مدرّب. يمكن إدخال أي نص عربي أو إنجليزي، وتظهر أمثلة عربية فقط عند اختيار الواجهة العربية.

### جديد: تغيير علامة الترقيم بنقرة واحدة

اضغط **استكشف النص** ثم **✨ بدّل علامة الترقيم**. ستضاف علامة أو تتغير، ثم تعاد التجربة وتُعرض مقارنة عدد الأجزاء قبل وبعد التغيير. يمكن الضغط على الأجزاء لرؤية أرقامها.

**الفكرة:** قد يؤثر تغيير بسيط في علامات الترقيم على طريقة تقسيم النص وتمثيله بالأرقام. تعمل التجربة دون نموذج كبير أو مفتاح API.
