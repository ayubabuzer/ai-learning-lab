# 🤖 بناء ونشر توأم رقمي حقيقي باستخدام uv وGradio وHugging Face ZeroGPU

**[English](README.md) · العربية**

هذا مشروع التوأم الرقمي الحقيقي في مختبر تعلم الذكاء الاصطناعي. نتبع **خطوات إد دونر**: تعديل ملف الشخصية، تشغيل `uv run app.py`، تسجيل الدخول إلى Hugging Face، ثم النشر بأمر `uv run gradio deploy`. الفرق هو أننا نستعمل **نموذجًا مفتوحًا يعمل داخل ZeroGPU** بدل واجهة نموذج مدفوعة.

**الخصوصية أولًا:** استخدم شخصية خيالية، ولا تنشر بيانات طفل حقيقي أو اسمه أو عنوانه أو مدرسته أو بريده الإلكتروني.

## قبل البدء

تحتاج إلى Git و[uv](https://docs.astral.sh/uv/getting-started/installation/) واتصال إنترنت وجهاز يسمح بتثبيت Python. التشغيل **المحلي** ينزّل عدة غيغابايت من ملفات النموذج وقد يكون بطيئًا دون معالج رسومي. بعد نشر Space لن يحتاج الزائر إلى تنزيل النموذج على جهازه.

لإنشاء ZeroGPU مجانًا يجب أن يكون حساب Hugging Face الشخصي **مؤكّد البريد، أقدم من 30 يومًا، وبحالة جيدة** وألا يتجاوز حد مساحتين من نوع ZeroGPU. قد توجد طوابير انتظار وحدود استخدام يومية. راجع [الشروط الحالية](https://huggingface.co/docs/hub/spaces-zerogpu).

## ١. استنسخ المشروع

```bash
git clone https://github.com/ayubabuzer/ai-learning-lab.git
cd ai-learning-lab/lessons/06-digital-twin/gradio-app
```

أو فك ضغط ملف المشروع وافتح **مجلد `gradio-app` نفسه**. نفّذ أمر النشر داخل هذا المجلد، وليس من جذر الموقع.

## ٢. ثبّت uv

اتبع [التعليمات الرسمية](https://docs.astral.sh/uv/getting-started/installation/). في Windows PowerShell:

```powershell
winget install --id=astral-sh.uv -e
```

على macOS باستخدام Homebrew:

```bash
brew install uv
```

وتحقّق من نجاح التثبيت:

```bash
uv --version
```

## ٣. خصّص شخصيتك

افتح `about-me.txt` واستبدل حقائق الشخصية الخيالية «أليكس» بمعلومات خيالية من تأليفك. يُستخدم الملف عند تشغيل التطبيق كنص معرفة افتراضي. تعديلات الزوار داخل واجهة الدردشة مؤقتة ولا تغيّر الملف المنشور.

## ٤. شغّل التطبيق محليًا مثل إد

```bash
uv run app.py
```

سيتولى uv إعداد Python والمكتبات. عند أول تشغيل تُنزّل ملفات النموذج وقد يستغرق ذلك وقتًا. افتح عنوان Gradio المحلي (غالبًا <http://127.0.0.1:7860>) واسأل: **ما اسمك؟**

إذا كان جهاز المدرسة غير مناسب لتشغيل النموذج، استخدم جهاز المعلم للاختبار ثم انشر المشروع على ZeroGPU. الدروس الأخرى في الموقع ما زالت خفيفة وسريعة.

## ٥. أنشئ حساب Hugging Face

سجّل عبر <https://huggingface.co/join> وأكّد بريدك وتحقق من [أهلية ZeroGPU](https://huggingface.co/docs/hub/spaces-zerogpu). أنشئ رمز وصول بصلاحية **الكتابة** من <https://huggingface.co/settings/tokens>.

في الطرفية نفسها:

```bash
uvx hf auth login
uvx hf auth whoami
```

أدخل رمزك في نافذة تسجيل الدخول الرسمية فقط. **لا تضع الرمز في `app.py` أو `about-me.txt` أو مستودع عام.** لا تحتاج إلى مفتاح API لنموذج مدفوع.

## ٦. انشر المشروع بأمر إد نفسه

داخل `gradio-app`:

```bash
uv run gradio deploy
```

عند ظهور الأسئلة، اختر:

| السؤال | إجابتك |
|---|---|
| اسم Space | اسم من اختيارك مثل `my-learning-lab-twin` |
| ملف التطبيق | `app.py` |
| **الأجهزة** | **`zero-a10g` أي ZeroGPU، ولا تقبل `cpu-basic` الافتراضي** |
| الأسرار | `n`، لا توجد مفاتيح نموذج مطلوبة |
| إجراء GitHub | `n`، ويمكن إضافته لاحقًا |

**لماذا؟** استخدم إد CPU Basic عند تصوير درسه، لكن إنشاء Gradio Space عادي على CPU Basic أصبح غالبًا يحتاج اشتراكًا. الحسابات المجانية المؤهلة يمكنها إنشاء ZeroGPU. لهذا نكتب `zero-a10g` صراحة. إن لم يظهر سؤال الأجهزة، افتح **Settings → Hardware** في Space وتحقق من اختيار **ZeroGPU**؛ وقد تحتاج إلى تعديل إعدادات Space الموجودة سابقًا.

بعد نشر الملفات يظهر رابط عام. يُنزّل Space النموذج عند الإعداد الأول، ثم يمكنك اختبار الإجابات ومشاركة الرابط.

إن فشل الإنشاء، تحقق من عمر حسابك والبريد المؤكد وأهلية ZeroGPU والحد المتاح لك. لا يمكن تجاوز سياسة Hugging Face؛ ويظل المشروع صالحًا للتشغيل المحلي.

## ٧. اختبر التوأم الرقمي

اسأل عن حقيقة موجودة في `about-me.txt`، ثم غيّر صياغة السؤال وجرّب العربية. اسأل عن عمر الشخصية إذا لم تذكره؛ يجب أن يقول المساعد «لا أعرف»، لكن **النموذج اللغوي قد يخطئ**. قارن بين إجابة الروبوت والنص المحتمل ذي الصلة في لوحة مستقلة. التطابق لا يعني أن الإجابة صحيحة بالضرورة. إذا كانت الخدمة مشغولة أو انتهى الحد المجاني، حاول لاحقًا.

## كيف يعمل؟

يحمّل التطبيق نموذجًا لغويًا متعدد اللغات حقيقيًا من <https://huggingface.co/Qwen/Qwen3-1.7B>. ويُرسل معلومات الشخصية والسؤال وسياق الحوار المؤقت إلى النموذج. **لا يُدرَّب النموذج من جديد ولا تُحفظ المحادثات دائمًا.** يعرض التطبيق سطرًا مرتبطًا محتملًا من المعلومات بشكل منفصل عن الإجابة. لا توجد واجهة نموذج مدفوعة أو مفتاح API خارجي.

الملفات الأساسية: `app.py` و`twin_core.py` و`about-me.txt` و`pyproject.toml` و`requirements.txt` و`.python-version`. تُستخدم مكتبات Gradio و`spaces` التي توفّرها بيئة Hugging Face عند النشر.
