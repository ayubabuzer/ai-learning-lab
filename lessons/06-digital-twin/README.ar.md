# الدرس ٠٦ — ابنِ توأمك الرقمي

**[العربية](README.ar.md) · [English](README.md)**

أنشئ مساعداً خيالياً يعتمد على ملف `.txt` يحتوي حقيقة في كل سطر. تميّز الصفحة بين **⚙️ المعلومات والإعدادات** و**✍️ السؤال** و**🤖 الإجابة** و**📖 المصدر الأصلي**. تبدأ الإجابة فارغة حتى تضغط على «اسأل»، ثم يظهر رمز تفكير قصير.

مع بيانات المثال العربي، عند السؤال **«ما اسمك؟»** يجيب المساعد **«اسمي نور.»** ويعرض السطر الأصلي كاملاً في مساحة الدليل. وعند السؤال **«كم عمرك؟»** دون وجود معلومة عن العمر يجيب **«لا أعرف»**.

يعتمد التطبيق على قواعد بسيطة واستخراج عبارات، وليس نموذجاً لغوياً يولّد جميع الأجوبة. قد يعرض جملة أصلية في بعض الحالات، ولا يعني ظهور مصدر أن محتواه صحيح بالضرورة. استخدم معلومات خيالية ولا تنشر معلومات الأطفال الشخصية.

## تشغيل مشروع Gradio ونشره اختيارياً

يتضمن الدرس مشروعاً في مجلد [`gradio-app/`](gradio-app/) ودليل [إعداد عربي](gradio-app/README.ar.md) يشرح استنساخ GitHub، وتثبيت Python والمتطلبات، وتشغيل البرنامج محلياً، وإنشاء حساب Hugging Face والنشر الاختياري.

**مهم:** قد تتطلب الاستضافة العامة لتطبيق Gradio خطة مدفوعة أو استضافة مؤهلة محدودة؛ لا تشغّل Static Spaces المجانية تطبيقات Python. يمكن إكمال المشروع محلياً دون استضافة.
