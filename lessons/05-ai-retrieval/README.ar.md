# الدرس ٠٥ — كيف يحدد الذكاء الاصطناعي الكلمات التي ينظر إليها؟

[English](README.md) · [افتح مستكشف الانتباه](index.html)

## الفكرة

تتعلم النماذج الحقيقية أرقامًا خلال التدريب تساعد أجزاء النص على تبادل المعلومات. تعرض هذه التجربة **أوزانًا محسوبة** بحاسبة تعليمية بسيطة؛ ولا تعرض أوزان انتباه من نموذج مدرّب. مجموع الأوزان ١٠٠٪، لكنها **ليست نسب ثقة أو دليلاً على المعنى**.

## جرب صغيرًا وكبيرًا

1. اختر **جرّب صغيرة** ثم استكشف الانتباه؛ تُحدد «لأنها» تلقائيًا.
2. قارن الوزن الذي تحصل عليه «الكرة» والوزن الذي تحصل عليه «الحقيبة».
3. اضغط **غيّر إلى كبيرة**، وراقب كيف تتبدل الأوزان المحسوبة.
4. جرب جملة أخرى بنفسك: تُعاد الحسابات لأي نص قصير، لكن الحاسبة لا تضمن فهم الضمائر أو العلاقات في الجمل الجديدة.

قانون تبديل الوزن عند صغيرة/كبيرة وضعناه خصيصًا للتوضيح، **وليس نتيجة تدريب نموذج لغوي**. وتوجد إعدادات إضافية للكلمات المتشابهة في الشكل أو المتجاورة. تعمل التجربة دون إنترنت أو مفاتيح API.
