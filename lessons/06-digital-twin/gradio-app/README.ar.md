# التوأم الرقمي — نموذج Gradio (الدرس ٠٦)

هذا تطبيق خفيف **لاسترجاع النصوص** وليس نموذج Qwen لتوليد الكلام. يقتبس سطراً مطابقاً من ملف معرفة لشخصية خيالية ويُظهر رقم السطر. إذا لم يجد كلمات مشتركة كافية، يقول **لا أعرف**. قد لا يتعرف إلى كل سؤال بصياغة مختلفة، وقد لا تكون الجملة المطابقة إجابة كاملة.

## التشغيل المحلي (على جهاز المعلم أو المطور)

1. ثبّت Python 3.10 أو أحدث.
2. افتح الطرفية داخل هذا المجلد.
3. شغّل `python -m pip install -r requirements.txt`.
4. شغّل `python app.py`.
5. افتح العنوان المحلي الذي يعرضه Gradio.

لا يحتاج تلاميذ الموقع الثابت إلى Python أو تنزيل نموذج. يتطلب تثبيت Gradio اتصالاً بالإنترنت في البداية.

## التجربة والنشر الاختياري

عدّل `about-me.txt` واستخدم شخصية **خيالية** دون بيانات أطفال حقيقية. اكتب حقيقة في كل سطر. جرّب سؤالاً يتوفر جوابه وسؤالاً لا يتوفر. يمكن نشر التطبيق اختيارياً على Hugging Face Spaces وفق شروط الاستضافة المتاحة، لكن البيانات المرسلة إلى التطبيق المستضاف تُعالَج على الخادم، خلافاً لنشاط المتصفح المحلي. لا تنشر معلومات شخصية للأطفال.

هذا أساس للاسترجاع الموثق، **وليس** مساعداً توليدياً مدعوماً بـ Qwen. يمكن تطوير ذلك لاحقاً إذا توفرت خدمة حقيقية مناسبة.
