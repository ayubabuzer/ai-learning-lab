# Upload Lesson 01 to GitHub

1. Back up your current repository files. This ZIP was assembled from earlier AI Learning Lab packages, **not downloaded from your live repository**. Review differences before overwriting customized files.
2. Extract the ZIP and upload the contents into the **root** of `ayubabuzer/ai-learning-lab`, preserving the folder structure.
3. Replace existing `index.html`, `README.md`, `README.ar.md`, and `CHANGELOG.md` as needed.
4. Add `lessons/01-tokens/` (and preserve `lessons/01-next-word/`, an older optional bonus experiment).
5. Keep existing `LICENSE`, assets and custom files; this ZIP intentionally does not delete them.
6. Commit: `feat(lesson-01): publish bilingual tokens lesson and sync learning path`.
7. After GitHub Pages deploys, open `https://ayubabuzer.github.io/ai-learning-lab/lessons/01-tokens/`. Test English and Arabic, the three splitting modes, Reset, challenges and mobile layout.

Note: `lessons/02-tokens/` from the previous draft package, if previously uploaded, is superseded by `lessons/01-tokens/`; remove the outdated path only after confirming no important external links or custom changes depend on it.
