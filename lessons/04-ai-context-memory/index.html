LESSON 04 · CONVERSATION CONTEXT

How does AI remember a conversation?

A chat app can include earlier messages so the AI can answer using what you told it. Try keeping and clearing a fact.

💬 GUIDED CHAT

1 · Give the assistant a fact

🗃️ CONVERSATION CONTEXT

2 · What can the assistant see?

Only the facts included in the context are available to answer the next question.

Clearing context keeps the visible chat on screen, but removes its facts from the next answer. Ask the same question again.

📖 Why does the answer change?

The assistant can answer only while the fact is included in the context. Removing it means the same question no longer has that information. This guided demo is not a live AI model or permanent saved memory.
