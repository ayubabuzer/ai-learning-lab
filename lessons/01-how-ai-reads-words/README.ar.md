# الدرس ٠١ — كيف يقرأ الذكاء الاصطناعي كلماتنا؟

[English](README.md) · [افتح الدرس](index.html)

**سؤال بسيط:** ماذا يحدث بعد أن ترسل رسالة للذكاء الاصطناعي؟

**الشرح:** يعمل الحاسوب بالأرقام. لكل حرف رقم قياسي في Unicode. ثم تقسم النماذج اللغوية النص إلى رموز لها أرقام خاصة بها، وتحوّلها إلى تمثيلات عددية وتستخدم الأنماط التي تعلمتها لتكوين رد.

**جرّب:** اكتب **أي نص عربي أو إنجليزي**. اضغط الاستكشاف لترى أجزاء النص، ثم اضغط أي جزء لتشاهد **الأرقام الحقيقية لحروفه**. غيّر علامة ترقيم وقارن النتيجة.

**الاكتشاف:** يحتفظ الحرف نفسه برقم Unicode نفسه. لكن هذه الأرقام **ليست معرّفات رموز نموذج لغوي** ولا تعبّر وحدها عن المعنى. أداة تقسيم النص هنا مبسّطة وليست أداة نموذج مدرب.

**التالي:** في الدرس ٠٢ نستكشف العلاقات بين الكلمات، ثم نرى شرحاً مصوّراً عن الانتباه.

لا تحتاج التجربة إلى إنترنت أو مفتاح API أو نموذج لغوي كبير.
