From installing Python to a public Digital Twinمن تثبيت بايثون إلى توأم رقمي منشور

A simple course, one step at a time. Choose your computer, then follow the commands in order.دليل قصير خطوة بخطوة. اختر نظام جهازك ثم نفّذ الأوامر بالترتيب.

01

Open PowerShellافتح PowerShell

Search for PowerShell from the Windows Start menu.ابحث عن PowerShell من قائمة ابدأ في Windows.

02

Install Gitثبّت Git

Check whether Git is installed. If missing, install it with winget, then restart PowerShell.تحقق من وجود Git، وإذا لم يكن موجودًا فثبّته باستخدام winget ثم أعد فتح PowerShell.

git --version
winget install --id Git.Git -e
Git for Windows · Git لويندوز
03

Install uvثبّت uv

uv manages Python and the app dependencies. Restart PowerShell after installation.يدير uv بايثون وحزم التطبيق. أعد فتح PowerShell بعد تثبيته.

winget install --id astral-sh.uv -e
uv --version
uv install guide · دليل التثبيت
04

Install Python 3.12ثبّت بايثون 3.12

uv installs Python for the project. You do not need to replace your system Python.يثبّت uv إصدار بايثون المناسب للمشروع دون تغيير بايثون النظام.

uv python install 3.12
uv python find 3.12
05

Clone just Lesson 06نزّل الدرس السادس فقط

Clone the repository in sparse mode. Only Lesson 06 (plus small root files) will appear in your working folder. Use a fresh folder; if you already cloned the project, skip this step.استخدم النسخ الجزئي لتنزيل ملفات الدرس السادس فقط (مع ملفات الجذر الضرورية). إذا نسخت المستودع سابقًا فتخطَّ هذه الخطوة.

git clone --depth 1 --filter=blob:none --sparse https://github.com/ayubabuzer/ai-learning-lab.git
06

Open the Digital Twin folderافتح مجلد التوأم الرقمي

Select Lesson 06 with sparse checkout, then enter the Gradio app folder. If you already cloned the repository, just open your existing gradio-app folder.اختر الدرس السادس ثم افتح مجلد التطبيق. إذا كنت قد استنسخت المستودع سابقًا، افتح مجلد gradio-app الموجود لديك.

cd ai-learning-lab
git sparse-checkout set lessons/06-digital-twin
cd lessons/06-digital-twin/gradio-app
07

Personalise your knowledge fileخصّص ملف المعلومات

Edit about-me.txt and save a fictional profile. Do not publish private information.افتح about-me.txt وأدخل معلومات لشخصية خيالية. لا تنشر أي معلومات شخصية.

open -e about-me.txt
08

Try the chatbot locally (optional)جرّب المحادثة محليًا (اختياري)

uv installs the dependencies and starts Gradio. The model download can be several gigabytes; on a basic computer, you may skip this test.يثبّت uv الحزم ثم يشغّل Gradio. قد يحتاج النموذج إلى تنزيل عدة غيغابايت، ويمكن تخطي التجربة على الحواسيب الضعيفة.

uv run app.py
09

Create and verify your Hugging Face accountأنشئ حساب Hugging Face وفعّله

Sign up and confirm your email. For free ZeroGPU Spaces, your personal account must be eligible and older than 30 days.سجّل حسابًا وأكّد البريد الإلكتروني. لاستضافة ZeroGPU المجانية يجب أن يكون حسابك الشخصي مؤهلًا وقد مرّ على إنشائه أكثر من 30 يومًا.

Create account · إنشاء حسابZeroGPU requirements · شروط ZeroGPU
10

Sign in safely from the terminalسجّل الدخول بأمان من الطرفية

If asked, create a write-capable token. Keep it private; never paste it into public files.عند الطلب، أنشئ رمز وصول بصلاحية الكتابة. احتفظ به سرّيًا ولا تضفه إلى ملفات عامة.

uvx hf auth login
uvx hf auth whoami
Access tokens · رموز الوصول
11

Deploy with Gradio and choose ZeroGPUانشر باستخدام Gradio واختر ZeroGPU

From the Gradio project folder, run the same deployment command used in the course. Choose zero-a10g where hardware selection is offered. If not, verify the hardware in Space Settings before using the app.من مجلد تطبيق Gradio، شغّل أمر النشر المستخدم في الدورة. اختر zero-a10g عند ظهور قائمة الأجهزة، أو تحقق من الإعدادات داخل Space قبل الاستخدام.

uv run gradio deploy

⚠️ Select zero-a10g, not cpu-basic. Free hosting requires an eligible account; queues and limits apply. The deploy tool may not offer hardware selection in every version—verify it on Hugging Face.⚠️ اختر zero-a10g وليس cpu-basic. تتطلب الاستضافة المجانية حسابًا مؤهلًا، وقد توجد طوابير وحدود استخدام. قد لا يظهر اختيار العتاد في بعض إصدارات أداة النشر؛ تحقّق من إعدادات Hugging Face.

12

Test your public link and share itجرّب الرابط العام ثم شاركه

Wait for the Space to finish building. Test the English-only chatbot, ask a question not in your profile, and share your Space link. GPU queues or quotas can mean trying again later.بعد اكتمال إنشاء Space، جرّب المحادثة بالإنجليزية فقط وسؤالًا ليس له جواب في الملف، ثم شارك الرابط. قد تحتاج إلى المحاولة لاحقًا عند ازدحام الخدمة.

01

Open Terminalافتح Terminal

Press Command + Space, type Terminal, then press Return.اضغط Command + Space واكتب Terminal ثم اضغط Return.

02

Install Gitثبّت Git

Check for Git. If macOS offers Command Line Tools, accept; otherwise run the install command shown.تحقق من وجود Git. إذا طلب macOS تثبيت أدوات سطر الأوامر فوافق، أو نفّذ الأمر التالي.

git --version
xcode-select --install
Git for Mac · Git لماك
03

Install uvثبّت uv

If Homebrew is installed, use brew. Otherwise use the official uv installer (choose one method). Open a new Terminal afterwards.إذا كان Homebrew موجودًا فاستخدم brew، وإلا فاستخدم مثبّت uv الرسمي (اختر طريقة واحدة). افتح Terminal من جديد بعد التثبيت.

OR · أو

brew install uv
curl -LsSf https://astral.sh/uv/install.sh | sh
uv --version
uv install guide · دليل التثبيت
