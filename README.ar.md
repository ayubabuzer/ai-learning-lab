# AI Learning Lab | مختبر تعلم الذكاء الاصطناعي

**[العربية](README.ar.md) · [English](README.md) · [الموقع](https://ayubabuzer.github.io/ai-learning-lab/)**

**تعلّم كيف يعمل الذكاء الاصطناعي من خلال تجارب حقيقية وممتعة، دون رياضيات معقدة أو خبرة بالبرمجة.**

مختبر تعلّم الذكاء الاصطناعي مشروع تعليمي مجاني ومفتوح المصدر بالعربية والإنجليزية لجميع الأعمار. يتضمن كل درس تجربة تفاعلية وشرحاً مبسطاً وتحديات ودليلاً للمعلم. يعتمد الموقع التصميم الداكن الحالي ويعمل على GitHub Pages.

## نبدأ بالدرس الأول

### [كيف يقرأ الذكاء الاصطناعي كلماتنا؟](lessons/01-how-ai-reads-words/) — منشور

**ماذا يحدث للجملة قبل أن يعالجها نموذج الذكاء الاصطناعي؟** يكتب التلميذ أي نص بالعربية أو الإنجليزية ويتوقع عدد الأجزاء، ثم يستخدم **مُقسِّم رموز Qwen متعدد اللغات الحقيقي**، ويضغط الرموز الملونة لرؤية **معرّفاتها الرقمية الفعلية**، ويقارن ذلك بوضع بايتات UTF‑8 الذي يعمل دون إنترنت. يجرّب الرموز التعبيرية والترقيم وتغيير الحروف ويشرح النتائج المفاجئة.

يتطلب وضع مُقسِّم النموذج اتصالاً بالإنترنت في البداية لتنزيل ملفاته المجانية. وضع البايت ليس قاموس النموذج الجاهز. لا نشغّل نموذجاً لتوليد النص هنا. معرّفات الرموز ليست متجهات؛ سنتعرف عليها في الدرس الثاني.

## للمعلمين

اقرأ [دليل المعلم](TEACHERS.ar.md) لخطة لعبة صفية مدتها ٢٥ دقيقة مع الإعداد والتحديات والمفاهيم الخاطئة الشائعة. [English teacher guide](TEACHERS.md). يوجد الدليل أيضاً داخل صفحة الدرس.

## مبادئنا

- لا يحتاج درس المتصفح إلى مفاتيح API مدفوعة أو اشتراك أو حساب.
- محتوى حقيقي بالعربية والإنجليزية مع اتجاه كتابة مناسب.
- نوضح الفرق بين **نتائج النماذج الحقيقية** والأمثلة التعليمية.
- في كل درس: توقّع ← جرّب ← غيّر ← اشرح ← تحدَّ.
- تجنب جمع بيانات التلاميذ الخاصة، واستخدام أمثلة خيالية.
- سيعمل مشروع Gradio النهائي محلياً مجاناً، أما النشر على Hugging Face فهو اختياري ويتوقف على شروط الاستضافة الحالية.

## المساهمة والتراخيص

شارك أفكارك وملاحظاتك عبر المستودع. نحترم ترخيص المستودع الحالي. كل تحديث لدرس يصاحبه تحديث لهذه الصفحة و[README.md](README.md) والصفحة الرئيسية ودليل المعلم و[CHANGELOG.md](CHANGELOG.md).

## لماذا أداة ترميز Qwen؟

يستخدم الدرس ملفات أداة الترميز الحقيقية لنموذج Qwen3 0.6B دون تنزيل أوزان النموذج اللغوي الكامل أو توليد إجابات. يحتاج وضع الترميز إلى تنزيل أولي صغير، بينما يظل وضع البايت التعليمي متاحاً دون تنزيل نموذج.


**تحسين عرض العربية:** نحافظ على معرّفات رموز Qwen الأصلية، وقد نجمّع الرموز المتجاورة لعرض أحرف مفهومة دون تغيير الأرقام. يعرض قسم التفاصيل جميع المعرفات، وتظهر واجهة العربية من اليمين إلى اليسار.
