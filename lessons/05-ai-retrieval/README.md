# Lesson 05 — How AI uses tools and agents

[Arabic guide](README.ar.md) · [Open lesson](index.html)

**The tool experiment:** Choose one of three prepared questions. Enable or disable the weather, calculator or search tool, and ask the **same question again**. The conversation shows the selected tool, an example tool result and the assistant reply. The weather question gives a forecast only when the weather tool is enabled. Without search, the assistant can recall the Apollo 11 date from general knowledge but cannot claim to have checked a source. The simple `5 × 2` calculation still works without the calculator, although no calculator tool call is shown.

**What is an agent?** Read the explanation, then run either prepared goal. In the **picnic** example, the assistant recommends Sunday only when the example forecast is available; otherwise it asks the student to check the weather. In the **headphones** example, two searches are shown: the first fictional products fail the budget/ANC requirements and the second finds fictional Option C. With search disabled the assistant gives buying criteria, not an unverified product recommendation. Calculator ON/OFF changes whether the agent calls a calculator for the £5 remaining, not the final arithmetic result.

All tool results, product names and forecasts are **fictional teaching examples**. No live search, weather service, or language model is contacted. The animated trace illustrates observable actions, not a model's private reasoning. **Start again** resets the run.
