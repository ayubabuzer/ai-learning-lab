From your computer to a public link

A practical, step-by-step path to run the project and optionally deploy it.

01

Get the project

Install Git and Python, then clone the public repository.

git clone https://github.com/ayubabuzer/ai-learning-lab.git
cd ai-learning-lab/lessons/06-digital-twin/gradio-app
02

Install the requirements

Use Python 3.11 or newer. Create a virtual environment if you can, then install Gradio.

python -m venv .venv
# Activate .venv for your operating system
pip install -r requirements.txt
03

Run and personalise

Edit about-me.txt with imaginary facts, then run the Gradio app. Open the local address it shows.

python app.py
04

Create a Hugging Face account

Register, then create a new Space with the Gradio SDK. Check your plan and hosting eligibility first.

Create account ↗Create Space ↗
05

Publish and share

Upload app.py, requirements.txt, about-me.txt and the Gradio README.md to the ROOT of your Space. Once it builds, share its public URL if hosting is enabled.

Read the full deployment guide ↗

Important about free hosting: This browser course is free. A Python-powered public Gradio Space may require a paid Hugging Face plan or qualifying hosting access; free Static Spaces cannot run this Python app. Local use remains available.
