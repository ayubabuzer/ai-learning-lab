# الدرس ٠٥ — كيف يستخدم الذكاء الاصطناعي الأدوات والوكلاء؟

[English](README.md) · [افتح الدرس](index.html)

**تجربة الأدوات:** اقرأ تعليمات المطور مثل «عندما يسأل شخص عن الطقس، استخدم weather_forecast». اختر سؤالاً جاهزاً؛ ستعرض المحادثة السؤال واستدعاء الأداة والنتيجة التوضيحية ورد المساعد. لا يحتاج الطلاب لكتابة سؤال مفتوح. عطّل أداة وأعد التجربة.

**ما الوكيل؟** اقرأ الشرح أولاً ثم اختر تجربة النزهة أو السماعات. انقر **تشغيل الوكيل** لتظهر الخطوات تلقائياً مع مؤشر «يختار الخطوة التالية» بينها. زر البدء من جديد يعيد المثال.

**الدقة:** هذه محاكاة محلية؛ نتائج البحث والطقس وخطوات الوكيل ليست بيانات حية أو قرارات نموذج حقيقي.
