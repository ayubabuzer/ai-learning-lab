# الدرس ٠٤ — كيف يتذكر الذكاء الاصطناعي المحادثة؟

[English](README.md) · [افتح الدرس](index.html)

اختر بطاقة معلومة جاهزة (الاسم، الكلب، الطعام أو المدينة). اسحبها إلى المحادثة أو اضغط عليها؛ ستظهر في المحادثة وفي لوحة السياق. اختر سؤالاً من القائمة ثم اسأل المساعد. امسح السياق وأعد السؤال لتلاحظ الفرق. زر البداية يعيد التجربة.

**الفكرة:** سياق المحادثة هو المعلومات التي تُرسل مع الطلب الحالي. هذه محاكاة محلية سريعة وليست نموذجاً حقيقياً أو ذاكرة دائمة. الضغط على البطاقة بديل متاح للسحب على الأجهزة اللمسية ولوحة المفاتيح.
