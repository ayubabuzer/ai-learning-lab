LESSON 01 · EXPLORE REAL AI TOKENISATION

How Does AI Read Our Words?

Think of an AI as a puzzle solver: before it can work with a sentence, it turns the text into smaller pieces called tokens. Let's find out how a real tokenizer breaks up your words — and why the result might surprise you.

This lesson shows the tokenisation stage, not how AI understands meaning. Token IDs identify pieces; embeddings that represent patterns come in Lesson 02.

Classroom missions

Explorer 🧭

Find a sentence where the number of tokens is different from the number of words.

Builder 🛠️

Innovator 🔬

Compare the same sentence in Qwen3 0.6B and UTF‑8 byte mode. Explain why token IDs and counts differ.

Remember 💡

A tokenizer makes pieces and IDs. Later stages use learned vectors to represent patterns and help a model work with the context.

👩‍🏫 Teacher's guide — classroom game (25 minutes)

Learning objective

Explain that a tokenizer breaks text into pieces and assigns numerical IDs, and that these IDs are not meaning scores.

Before class

Open the lesson on a projector. Test the internet connection for the model tokenizer. Offline byte mode is available. Ask pupils not to enter real names, addresses or other personal information.

    Questions for discussion

    Why might a long word use several tokens? Is a token always a word? Does a higher ID mean a smarter word? What changes if we use another tokenizer?

    Exit ticket

    Each pair explains one surprise, using the words “token” and “ID”. Next: how can numbers help AI represent relationships between words?
