# Lesson 01 — How Does AI Read Our Words?

[العربية](README.ar.md) · [Open playground](index.html) · [Teacher guide](../../TEACHERS.md)

This lightweight bilingual lesson uses a **classroom text splitter** and classroom IDs, not a pretrained language-model tokenizer. Pupils enter any text, click pieces to inspect the numbers, and reconstruct the original input. English and Arabic each have their own suggested examples.

### New: one-click punctuation change

Choose an example and click **Explore my text**, then **✨ Change punctuation**. The button adds or switches a punctuation mark, reruns the experiment, and displays the before/after piece count. Pupils can inspect which classroom piece and ID changed. This works offline and does not require a model or API key.

**Teaching point:** A small change in punctuation can change the pieces and numbers a text-processing system sees. This is a demonstration, not Qwen tokenisation or model inference.
