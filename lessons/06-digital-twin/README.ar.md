# الدرس 06 — ابنِ توأمك الرقمي

[افتح الدرس](index.html) · [English](README.md) · [الرئيسية](../../)

**الفكرة:** يمكن أن يجمع التوأم الرقمي بين ملف معرفة والبحث والرد بمصدر واضح. الأهم هو التفريق بين المعلومات المدعومة والمعلومات المفقودة.

**جرّب:** عدّل حقائق الشخصية الخيالية في ملف شبيه بـ `about-me.txt` (حقيقة في كل سطر) أو حمّل ملف `.txt` محلياً. اسأل أي سؤال وشاهد النص الداعم ورقم السطر. عندما لا يجد معلومة مناسبة يقول **«لا أعرف من المعلومات المتاحة»**. يمكنك حفظ الملف أو تجربة مشروع Python/Gradio المرفق.

**توضيح النموذج:** يعتمد تطبيق المتصفح ومثال Gradio على **استرجاع النصوص لا توليدها**. ليسا Qwen ولا نموذجاً لغوياً مدرباً أو معدلاً. ولا يضمنان فهم كل سؤال أو صحة كل معلومة. يقتبسان الأسطر المرتبطة ويتجنبان اختراع الإجابات. النشر عبر Hugging Face اختياري ويحتاج إلى حساب واستضافة مناسبة؛ أما تشغيل Gradio محلياً فيتطلب Python وتثبيت حزمة.

**الخصوصية:** استخدم شخصيات خيالية. لا تنشر أسماء الأطفال أو بيانات الاتصال أو أماكن سكنهم في المستودعات أو التطبيقات العامة.

## أنشطة الصف

1. توقّع النتيجة قبل الضغط على زر التجربة.
2. غيّر شيئاً واحداً في كل مرة ولاحظ الفرق.
3. اشرح ما الذي تحسبه الخوارزمية التعليمية وما الذي لا تستطيع فعله.

**المتطلبات:** متصفح حديث مع JavaScript، دون مفاتيح API أو تنزيل نموذج كبير أو حساب للطالب.
