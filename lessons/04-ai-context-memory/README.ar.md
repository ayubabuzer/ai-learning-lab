# الدرس ٠٤ — كيف يتذكر الذكاء الاصطناعي؟

[English](README.md) · [افتح الدرس](index.html)

**السؤال:** لماذا يبدو أن المساعد يتذكر معلومة من حديث سابق؟

**التجربة:** اختر نوع المعلومة (اسمك أو اسم كلبك أو الطعام المفضل أو المدينة) واكتب أي قيمة. اضغط **أضف المعلومة للمحادثة** ثم اختر سؤالاً مدعوماً واضغط **اسأل المساعد**. امسح السياق وأعد السؤال لتلاحظ اختلاف الرد. استخدم **ابدأ من جديد** لإعادة التجربة.

**الصدق التقني:** هذه محاكاة محلية موجّهة، وليست نموذجاً لغوياً. الأسئلة محددة لكن قيم المعلومات يكتبها المتعلم. لا تُرسل البيانات إلى خادم. تعرض التجربة سياق المحادثة المؤقت لا الذاكرة الدائمة أو تدريب النموذج.

**التالي:** الدرس ٠٥ يشرح الأدوات والوكلاء.
