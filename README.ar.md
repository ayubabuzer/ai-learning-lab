# مختبر تعلم الذكاء الاصطناعي | AI Learning Lab

**[العربية](README.ar.md) · [English](README.md) · [الموقع](https://ayubabuzer.github.io/ai-learning-lab/)**

موقع ثنائي اللغة مجاني لتعلّم أساسيات الذكاء الاصطناعي من خلال تجارب صغيرة وتفاعلية تناسب أجهزة المدرسة العادية. لا يحتاج الطلاب إلى حساب أو مفتاح API أو تنزيل نموذج لغوي كبير.

## تسلسل التعلّم

**أجزاء الكلمات → متجهات السياق → التنبؤ → السياق المؤقت → استرجاع المعلومات → مساعد يعتمد على المصادر.**

تتعلّم النماذج اللغوية الكبيرة من أمثلة هائلة من الكلمات والجمل في الكتب والمواقع الإلكترونية والقصص والمقالات وغيرها. هذه التجارب الصغيرة تساعدنا على فهم **بعض المبادئ** من خلال حسابات حقيقية وشفافة، لكنها **ليست** نماذج Qwen مدرّبة أو تطبيقات توليد متقدمة.

## النشر والتطوير

انقل الملفات إلى المستودع مع الإبقاء على ملف `LICENSE` وأي عمل مستقل موجود. لا تحذف المجلدات بلا مراجعة. يحتوي الإصدار على مجلد واحد لكل درس. بعد المراجعة والرفع، تحقّق من جميع الروابط في GitHub Pages. يمكن تشغيل مشروع Gradio المرفق محلياً باستخدام Python، والنشر الخارجي اختياري وقد يتطلب حساباً واستضافة مناسبة.

استخدم بيانات وشخصيات خيالية دائماً، ولا تنشر معلومات أطفال حقيقية.
