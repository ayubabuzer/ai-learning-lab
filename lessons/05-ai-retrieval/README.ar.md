# الدرس ٠٥ — كيف يستخدم الذكاء الاصطناعي الأدوات ويسعى لتحقيق هدف؟

[English](README.md) · [افتح الدرس](index.html)

**السؤال:** كيف يختار المساعد أداة، وكيف يواصل الوكيل اتخاذ خطوات لتحقيق هدف؟

**التجربة:** يحدد المطور أسماء الأدوات وأوصافها ومدخلاتها: الطقس والحاسبة والبحث. فعّل الأداة أو عطّلها ثم اطرح سؤالاً. تعرض الصفحة طلب الأداة ونتيجتها ورد المساعد. تحسب الحاسبة مسائل مثل `5 x 2` و`5 × 2`، لكن نتائج الطقس والبحث افتراضية.

**الوكيل:** اختر مثال النزهة مع بديل أو مثال سماعات ضمن الميزانية، ثم اضغط **تشغيل الوكيل** لتظهر الخطوات تلقائياً. اضغط **ابدأ من جديد** لإعادة العرض. الفكرة: هدف ← قرار ← إجراء ← ملاحظة ← متابعة أو توقف.

**الصدق التقني:** اختيار الأدوات يعتمد على قواعد مبسطة، ولا تُستدعى خدمات حقيقية. أمثلة الوكيل متسلسلات توضيحية، وليست تنفيذاً مستقلاً لنموذج لغوي.

**التالي:** الدرس ٠٦ يعرّف التوأم الرقمي كمساعد محادثة حقيقي، وليس وكيلاً مستقلاً.
