# مختبر تعلم الذكاء الاصطناعي | AI Learning Lab

**[English](README.md)** | العربية · [الموقع](https://ayubabuzer.github.io/ai-learning-lab/)

**افهم كيف يعمل الذكاء الاصطناعي — فكرة ممتعة في كل مرة.**

مشروع تعليمي مجاني ومفتوح المصدر باللغتين العربية والإنجليزية، يقدّم أنشطة تفاعلية بسيطة للمبتدئين من جميع الأعمار. لا تتطلب الدروس التمهيدية معرفة بالرياضيات أو البرمجة أو واجهات مدفوعة.

## ابدأ من هنا: الدرس ٠١

**[كيف يقرأ الذكاء الاصطناعي النص؟ الرموز](lessons/01-tokens/)** هو أول درس في مسارنا. اكتب نصاً عربياً أو إنجليزياً، واختر طريقة التقسيم وشاهد الأجزاء الملونة. يوضح الدرس الفرق بين أداة تعليمية مبسطة وأدوات الترميز الحقيقية.

تظل [تجربة التنبؤ بالكلمة التالية السابقة](lessons/01-next-word/) متاحة **كنشاط إضافي اختياري** وليست الدرس الأول في المسار الحالي. أبقينا اسم المجلد القديم حتى لا تتعطل الروابط السابقة.

| الرقم | الموضوع | الحالة |

ننشر ونختبر **درساً واحداً في كل مرة**. يحتاج مشروع Gradio النهائي إلى بيئة Python منفصلة؛ أما موقع GitHub Pages فيستضيف الدروس الثابتة.

## أسلوب التعلم

**شاهد ← جرّب ← افهم ← تحدَّ نفسك ← اربط الأفكار.** يبدأ كل درس بتجربة تفاعلية وشرح بسيط وتحديات للمستكشف والبنّاء والمبتكر. البرمجة اختيارية، مع أمثلة عربية حقيقية ودعم الاتجاه من اليمين إلى اليسار.

## الخصوصية والدقة

استخدم أمثلة خيالية أو نصوصاً غير حساسة، ولا تنشر بيانات التلاميذ الشخصية. هذه التجارب أدوات تعليمية مبسطة، وليست نماذج لغوية عصبية كاملة.
