# الدرس 04 — هل يتذكر الذكاء الاصطناعي حقاً؟

[افتح الدرس](index.html) · [English](README.md) · [الرئيسية](../../)

**الفكرة:** تختلف أوزان النموذج المكتسبة أثناء التدريب عن سياق المحادثة المؤقت، وعن المعلومات التي يحفظها التطبيق بشكل منفصل.

**جرّب:** اكتب حقائق من اختيارك واسأل أي سؤال. شغّل خيار **أرسل هذا النص مع سؤالي** أو أوقفه، وشاهد النص الذي يستقبله القارئ. اضغط **ابدأ جلسة جديدة** لمسح سجل التجربة واستعادة المثال.

**توضيح:** يستخدم هذا الإصدار **قارئاً يستخرج جملاً من النص** وليس نموذجاً لغوياً. يبحث عن كلمات مهمة مشتركة مع السؤال ويقتبس جملة ملائمة أو يوضح غياب معلومات مناسبة. لا تُدرّب أوزان نموذج ولا تُحفَظ النصوص تلقائياً على الإنترنت. إيجاد جملة مرتبطة لا يعني أن إجابة كاملة قد توفرت.

## أنشطة الصف

1. توقّع النتيجة قبل الضغط على زر التجربة.
2. غيّر شيئاً واحداً في كل مرة ولاحظ الفرق.
3. اشرح ما الذي تحسبه الخوارزمية التعليمية وما الذي لا تستطيع فعله.

**المتطلبات:** متصفح حديث مع JavaScript، دون مفاتيح API أو تنزيل نموذج كبير أو حساب للطالب.
