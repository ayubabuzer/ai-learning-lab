LESSON 01 · LIGHTWEIGHT PLAYGROUND

How Does AI Read Our Words?

When you read a sentence, you see words. A computer needs a way to work with text as numbers. Let's explore the journey using a simple, real browser experiment!

This is a simplified classroom text splitter, not large model or a real LLM tokenizer. The numbers are teaching labels assigned by this page. No model download is needed.

What happens after you send a message?

See the important stages: text → tokens → token IDs → learned vectors → prediction. The experiment below is a simplified splitter, not a pretrained tokenizer.

1 · Text / النصYou write a message. / تكتب رسالة.
2 · Tokens / الرموزA tokenizer breaks it into pieces, often whole words or word fragments. / يقسم المرمّز النص إلى أجزاء.
3 · Token IDs / أرقام الرموزEach token maps to an ID in that tokenizer's vocabulary. / لكل رمز معرّف رقمي في قاموس المرمّز.
4 · Vectors + prediction / المتجهات والتنبؤThe model looks up learned number vectors, processes context and predicts its next token. / يعالج النموذج السياق ويتنبأ بالرمز التالي.
🧭 Next concept · Word relationshipsالفكرة التالية · العلاقات بين الكلمات

How can numbers represent meaning?كيف يمكن للأرقام تمثيل المعنى؟

A model learns vectors that can reflect relationships and context. Imagine projecting them onto a simple map: related concepts may end up near each other.يتعلم النموذج متجهات رقمية قد تعكس العلاقات والسياق. تخيّل عرضها على خريطة مبسطة حيث قد تتقارب المفاهيم المرتبطة.

Illustration only: not actual model coordinates. Real vectors have many dimensions and word meaning depends on context.رسم توضيحي فقط، وليس إحداثيات نموذج حقيقي. المتجهات الفعلية متعددة الأبعاد ويتغير المعنى حسب السياق.

📖 Supporting information📖 المعلومات الداعمة

Optional · Character codes are different from model token IDs

Unicode identifies characters; a tokenizer identifies text pieces. These are different number systems. Inspect them here only if you are curious.

4 · Be a word detective

🧭 Change one word

Change “cat” to “elephant”. Which character numbers and text pieces change?

🔎 Try another sentence

Choose a different English sentence. Does the same character have the same Unicode number in every sentence?

🤖 Surprise the computer

Add spaces, punctuation or emoji. Can you make the number of pieces change?

What did we learn? A computer represents characters with real numbers. A language model turns text into its own tokens, learns numerical patterns and uses them to predict. Character numbers do not carry meaning by themselves. Next: how can numbers help words relate?

Project the playground. Work in pairs. No programming needed. Use fictional examples, not personal pupil details.
