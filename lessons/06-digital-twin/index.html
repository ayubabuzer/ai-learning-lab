THE SAME WORKFLOW AS ED · OPEN MODEL · ZERO GPU COST

From your computer to your own public chatbot

The project uses one real-model Gradio app. Follow these steps from the Digital Twin folder.

01

Get the files

Clone the AI Learning Lab repository and open the Digital Twin app folder.

git clone https://github.com/ayubabuzer/ai-learning-lab.git
cd ai-learning-lab/lessons/06-digital-twin/gradio-app
02

Install uv and customise

Install uv using its official guide. Then edit about-me.txt with facts about an imaginary character. No real private information.

Install uv ↗
uv --version
03

Run the AI locally

uv prepares Python and starts Gradio. The pretrained model downloads on first use; a teacher computer may be needed for local testing.

uv run app.py

Once deployed, visitors do not download the model—Hugging Face runs it remotely.

04

Sign in to Hugging Face

Create a personal account, verify the email and obtain a write token. Sign in via the terminal. Eligible free accounts must be older than 30 days.

uvx hf auth login
uvx hf auth whoami
Create HF account ↗Access tokens ↗
05

Deploy, test and share

Run Ed's deployment command from the gradio-app folder and choose ZeroGPU when Gradio asks for hardware. After the Space builds, share your public link.

uv run gradio deploy
⚠️ Hardware: enter zero-a10g (ZeroGPU). Do NOT accept the old cpu-basic default. Free ZeroGPU hosting requires an eligible personal account and has daily usage limits and queues.
Read complete commands and screenshots guidance ↗Check ZeroGPU eligibility ↗
🔒 Keep your Hugging Face access token private. Use a fictional profile. The chatbot may make mistakes; compare generated answers with the original facts. Busy/free-quota messages mean you should try again later.
