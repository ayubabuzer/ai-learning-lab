# الدرس ٠٦ — ابنِ توأمك الرقمي وانشره بنفسك

**[العربية](README.ar.md) · [English](README.md)**

بعد تعلم أجزاء النص والعلاقات بين الكلمات والتنبؤ والسياق والتحقق من الأدلة في الدروس السابقة، سنبني الآن **مساعدًا يستخدم نموذج ذكاء اصطناعي حقيقيًا لتوليد الإجابات**. يقرأ معلومات الشخصية الخيالية من `about-me.txt` ويستخدم سياق المحادثة الأخيرة ثم يكتب إجابة جديدة بالعربية أو الإنجليزية.

**نتبع خطوات إد دونر باستخدام uv وGradio:** استنسخ المشروع → ثبّت uv → عدّل ملف الشخصية → شغّل `uv run app.py` → سجّل الدخول بأمر `uvx hf auth login` → انشر باستخدام `uv run gradio deploy` → شارك رابط Hugging Face. **اختر `zero-a10g` (ZeroGPU) وليس `cpu-basic` الافتراضي القديم.**

[دليل النشر العربي الكامل](gradio-app/README.ar.md) · [English deployment guide](gradio-app/README.md). يُستخدم **المشروع نفسه** للتشغيل المحلي والنشر، بلا مستويات أو تطبيقات مختلفة.

**الفكرة التعليمية:** معلومات الشخصية سياق مؤقت وليست تدريبًا دائمًا للنموذج. يولّد النموذج إجابات طبيعية، لكنه قد يخطئ أو يخترع حقائق. يعرض التطبيق الإجابة والنص الداعم المحتمل في منطقتين منفصلتين حتى يتحقق التلميذ من صحة الإجابة.

**شروط الاستضافة:** يمكن للحساب الشخصي المؤهل (بريد مؤكد، عمر الحساب أكثر من 30 يومًا، وحالة جيدة) إنشاء مساحتين ZeroGPU مجانًا، مع طوابير انتظار وحدود استخدام يومية. لا نحتاج إلى مفتاح API لنموذج مدفوع. أما تشغيل النموذج محليًا فيحتاج تنزيل ملفات كبيرة وقد يكون بطيئًا على الحواسيب المدرسية البسيطة. **استخدم معلومات خيالية فقط.**
