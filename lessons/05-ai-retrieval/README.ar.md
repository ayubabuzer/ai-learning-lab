# الدرس ٠٥ — كيف يستخدم الذكاء الاصطناعي الأدوات ويعمل لتحقيق هدف؟

[English](README.md) · [افتح الدرس](index.html)

**السؤال:** كيف يستطيع المساعد إنجاز مهمة تحتاج إلى معلومات خارجية أو خطوات متعددة؟

**القصة المصوّرة:** اختر تخطيط يوم خارج المنزل أو تنظيم مكتبة. شاهد المراحل: يطلب الشخص المساعدة ← يشرح التطبيق الأدوات المتاحة للنموذج ← قد يطلب النموذج المدرّب أداة ومعطيات ← يتحقق التطبيق ويشغل الأداة ← تعود النتيجة إلى النموذج ← يمكن للنموذج صياغة رد.

**الفرق بين سير العمل والوكيل:** يتبع سير العمل خطوات أو فروعاً حُددت مسبقاً في التطبيق. يستطيع الوكيل اختيار بعض خطواته بنموذج لغوي، ثم مراجعة النتيجة وتكرار **يقرر ← ينفذ ← يراجع** حتى يحقق الهدف أو يصل إلى حد أو يحتاج إلى موافقة شخص. ليست الأنظمة الأكثر استقلالية أفضل دائماً.

**تنبيه مهم:** هذه **قصة تعليمية معدّة مسبقاً**، وليست نموذجاً حقيقياً أو اتصالاً بخدمة الطقس أو وكيلاً يعمل بنفسه. النتائج الافتراضية واضحة ومعلّمة.

مصادر المعلم: [Anthropic](https://www.anthropic.com/engineering/building-effective-agents) و[OpenAI](https://developers.openai.com/api/docs/guides/function-calling).

**التالي:** في الدرس ٠٦ سنبني توأماً رقمياً يتحدث باستخدام نموذج حقيقي، لكنه ليس وكيلاً مستقلاً.
