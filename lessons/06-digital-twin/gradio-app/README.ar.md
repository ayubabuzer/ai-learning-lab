# ابنِ توأمك الرقمي وشغّله وشاركه 🤖

هذا تطبيق تعليمي صغير يعتمد على **البحث في المعلومات واستخراجها من ملف نصي**، وليس نموذجاً لغوياً توليدياً مدرّباً مسبقاً. يقدّم الإجابة والمصدر بشكل منفصل، وقد يقول «لا أعرف» عندما لا يجد دليلاً كافياً.

## ١. المتطلبات

ثبّت Git وPython 3.11 أو إصداراً أحدث. لا تحتاج إلى مفتاح API ولا إلى تنزيل نموذج ذكاء اصطناعي ضخم. استخدم معلومات **خيالية** فقط، ولا تضع أي معلومات شخصية عن الأطفال في مشروع عام.

## ٢. انسخ المستودع

```bash
git clone https://github.com/ayubabuzer/ai-learning-lab.git
cd ai-learning-lab/lessons/06-digital-twin/gradio-app
```

## ٣. ثبّت المتطلبات

```bash
python -m venv .venv
```

فعّل البيئة الافتراضية: على Windows PowerShell شغّل `.\.venv\Scripts\Activate.ps1`، وعلى macOS وLinux شغّل `source .venv/bin/activate`. ثم:

```bash
python -m pip install -r requirements.txt
```

## ٤. شغّل التطبيق

```bash
python app.py
```

افتح الرابط المحلي الذي يظهر في الطرفية. اختر العربية، واضغط «تحميل مثال باللغة المختارة». جرّب «ما اسمك؟» وشاهد الإجابة ومصدرها. واسأل سؤالاً غير مذكور لتختبر عبارة «لا أعرف».

عدّل ملف `about-me.txt` لشخصية خيالية، أو اكتب المعلومات في مربع المعرفة داخل التطبيق.

## ٥. النشر الاختياري في Hugging Face

1. أنشئ حساباً على <https://huggingface.co/join> وتحقق من بريده الإلكتروني.
2. تحقق من شروط الاستضافة الحالية في <https://huggingface.co/docs/hub/spaces-overview>. **قد يحتاج تشغيل Gradio إلى خطة مدفوعة أو أهلية لاستضافة مجانية محدودة. الاستضافة الثابتة المجانية لا تشغّل تطبيقات Python.**
3. افتح <https://huggingface.co/new-space> وأنشئ Space من نوع **Gradio**، واختر عاماً فقط إذا كانت المعلومات خيالية وغير حساسة.
4. ارفع الملفات الأربعة في **جذر** Space: `app.py` و`requirements.txt` و`about-me.txt` و`README.md` الإنجليزي المزوّد بإعدادات Space في أعلاه.
5. بعد نجاح البناء، اختبر الإجابة والمصدر ثم شارك الرابط إن توفرت الاستضافة.

النشر ليس شرطاً لإكمال الدرس. يمكنك تشغيل التطبيق محلياً دون GPU أو حساب لخدمة نماذج خارجية.
