# مختبر تعلم الذكاء الاصطناعي | AI Learning Lab

**[العربية](README.ar.md) · [English](README.md) · [الموقع](https://ayubabuzer.github.io/ai-learning-lab/)**

موقع تعليمي تفاعلي مجاني باللغتين العربية والإنجليزية يناسب أجهزة المدرسة العادية. تعمل الدروس من ٠١ إلى ٠٥ في المتصفح دون حساب أو مفتاح API أو تنزيل نموذج كبير. أما الدرس ٠٦ فيشرح بناء ونشر تطبيق ذكاء اصطناعي حقيقي باستخدام uv وGradio وZeroGPU. تتوفر أزرار **السابق / التالي** في جميع الدروس، مع أمثلة عربية واتجاه كتابة من اليمين إلى اليسار.

## مسار الدروس الستة

| الدرس | نشاط الطلاب | توضيح مهم |
|---|---|---|
| [٠١ · كيف يقرأ الذكاء الاصطناعي كلماتنا؟](lessons/01-how-ai-reads-words/) | تقسيم النص إلى أجزاء وأرقام تعليمية | الأرقام ليست معرّفات حقيقية من نموذج لغوي كبير |
| [٠٢ · كيف يربط الذكاء الاصطناعي الكلمات؟](lessons/02-word-embeddings/) | متجهات السياق وخريطة الكلمات والحساب التوضيحي للملك والملكة | الحسابات من نصوص الأمثلة، والنقاط المتطابقة تُفصل بصرياً فقط؛ إحداثيات الرسم التوضيحي مخترعة |
| [٠٣ · كيف يتنبأ الذكاء الاصطناعي بما يأتي؟](lessons/03-next-word-prediction/) | تعليم نموذج صغير بجمل ورؤية نسب حسابية للكلمة التالية | عدّ أنماط من أمثلة التلميذ، وليس نموذجاً لغوياً توليدياً مدرّباً |
| [٠٤ · هل يتذكر الذكاء الاصطناعي حقاً؟](lessons/04-ai-context-memory/) | إدخال سياق مؤقت وطرح الأسئلة وتشغيل السياق وإيقافه | إدراج المعلومات مع السؤال ليس تدريباً دائماً للنموذج |
| [٠٥ · كيف يحدّد الذكاء الاصطناعي الكلمات التي ينظر إليها؟](lessons/05-ai-retrieval/) | اكتب جملة بالعربية أو الإنجليزية وانقر كلماتها لتشاهد روابط الانتباه والنسب الحسابية | حسابات حقيقية لخوارزمية تعليمية ثابتة، وليست أوزان انتباه من نموذج لغوي مدرّب |
| [٠٦ · ابنِ توأمك الرقمي](lessons/06-digital-twin/) | أنشئ روبوت محادثة حقيقيًا من ملف شخصية خيالية وانشره باستخدام uv وGradio | نموذج توليدي حقيقي على ZeroGPU مع شروط أهلية وحدود استخدام |

**مسار التعلم:** أجزاء النص ← العلاقات بين الكلمات ← التنبؤ ← السياق ← الانتباه ← بناء ونشر توأم رقمي حقيقي.

تتعلم النماذج اللغوية الكبيرة أنماطاً من نصوص كثيرة مثل **الكتب والمواقع الإلكترونية والقصص والمقالات والكلمات والجمل**. أما هذه الأنشطة التعليمية فتشرح بعض المبادئ بحسابات صغيرة حقيقية وشفافة، دون الادعاء بأنها نتائج نماذج لغوية متقدمة.

## ابنِ توأمك الرقمي وشاركه

تحتوي الصفحة الرئيسية والدرس السادس على **تبويبي Windows وMac (Windows افتراضيًا)**، مع تعليمات لتثبيت Git وuv وبايثون 3.12، ثم اتباع خطوات إد دونر باستخدام **uv وGradio**: استنساخ المشروع، وتثبيت uv، وتعديل `about-me.txt`، ثم تشغيل `uv run app.py`، وتسجيل الدخول بأمر `uvx hf auth login`، وأخيرًا النشر باستخدام `uv run gradio deploy`. عند اختيار الأجهزة يجب تحديد **`zero-a10g` (ZeroGPU)** وليس `cpu-basic`. يعمل النموذج المفتوح على خادم Hugging Face ولا يحتاج الزائر إلى مفتاح API مدفوع.

[الدليل الإنجليزي](lessons/06-digital-twin/gradio-app/README.md).

**تنبيه:** استضافة ZeroGPU مجانية للحسابات الشخصية المؤهلة (بريد مؤكد، عمر الحساب أكثر من 30 يومًا، حساب بحالة جيدة، حتى مساحتين)، ولها حدود استخدام وطوابير انتظار. يُنزّل التشغيل المحلي النموذج ويحتاج جهازًا مناسبًا. لا تنشر أي معلومات شخصية خاصة.

## للمعلمين والنشر

[دليل المعلم](TEACHERS.ar.md) · [English guide](TEACHERS.md). يحتوي كل درس على شرح باللغتين. راجع الملفات قبل رفعها، ولا تحذف ملفات العمل الموجودة دون مراجعة. لكل درس مجلد رسمي واحد فقط. بعد الرفع إلى GitHub Pages افحص الموقع المنشور.

**ملاحظة:** الدروس ٠١–٠٥ متاحة بالعربية والإنجليزية، أما تطبيق الدرس ٠٦ ودليل نشره فبالإنجليزية فقط.

### تحسينات تعليمية جديدة

- **الدرس ٠١:** زر تغيير علامة الترقيم يتيح مقارنة الأجزاء وأرقامها قبل التغيير وبعده.
- **الدرس ٠٥:** تعرض تجربة «صغيرة/كبيرة» مقارنة حسابية تعليمية لوزن الربط بين الضمير و«الكرة» أو «الحقيبة». يمكن كتابة أي جملة لإعادة الحساب، لكن الأوزان ليست من نموذج مدرّب ولا تضمن فهم المعنى.
