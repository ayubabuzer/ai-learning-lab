# Changelog — AI Learning Lab

## 2026-11-17 — Lightweight Lessons 03–06 + Lesson 02 axes diagram

- Added **Lesson 03: How Does AI Predict What Comes Next?** with editable example sentences, explicit training button, longest matching word pattern counts, calculated next-word percentages, evidence examples and bilingual learning challenges.
- Added **Lesson 04: Does AI Really Remember?** with arbitrary editable context, arbitrary questions, context on/off, exact visible input, fresh-session reset, and explicit model/context/storage distinctions.
- Added **Lesson 05: How Does AI Find Information?** with editable document passages and two computed retrieval methods: direct keyword overlap and cosine similarity of tiny concept-aware word vectors. Pretrained embeddings are **not** claimed.
- Added **Lesson 06: Build Your Own AI Digital Twin** with editable or locally uploaded `.txt` knowledge, cited extractive evidence, missing-information responses, and optional bilingual Gradio starter project with fictional facts.
- Improved **Lesson 02** with an accessible static king/man/woman/queen axes map, numerical `[3,1] − [1,1] + [1,3] = [3,3]` arithmetic, invented-coordinate disclaimer and Arabic labels. The calculated main playground remains intact.
- Preserved **Lesson 01** from the latest simplified bilingual release, including Arabic RTL and no unnecessary UTF-8/hex numbers in pupil-facing content.
- Updated homepage to link directly to all six lessons, root English/Arabic READMEs, English/Arabic teacher guides, individual lesson guides and release instructions.
- No pretrained model, hosted inference provider or external API is required for the browser lessons. This release does **not** claim live Qwen model inference.
- Tested core user interactions locally in Chromium, JS syntax with Node and Gradio functions in Python. See `TEST-REPORT.md` for scope and limitations.
